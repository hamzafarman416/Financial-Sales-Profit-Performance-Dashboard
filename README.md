Financial Sales & Profit Performance Dashboard

(Excel | SQL | Power BI)

📌 Project Overview

This project demonstrates an end-to-end data analysis workflow using a sample financial sales dataset.
The objective is to analyze sales performance, profitability, product trends, and regional insights to support data-driven decision-making.

⚠️ Note: This project uses a public/sample dataset and does not contain any real company or confidential data.

🛠 Tools & Technologies

Excel – Data cleaning, preparation, and pivot analysis

SQL – Data querying, aggregation, and trend analysis

Power BI – Interactive dashboards, KPIs, and DAX measures

📊 Dataset Description

700+ sales transaction records

Key fields include:

Country

Product

Segment

Sales

Profit

Units Sold

Discount Band

Date (Month / Year)

The dataset was cleaned and structured to ensure accuracy and consistency before analysis.

🔍 Analysis Performed

Country-wise sales and profit analysis

Product-level profitability evaluation

Segment performance comparison

Discount impact on profit margins

Monthly and yearly sales trend analysis

📈 Power BI Dashboard Features

The Power BI dashboard includes:

KPI Cards

Total Sales

Total Profit

Profit Margin (%)

Units Sold

Interactive Visuals

Sales by Country

Profit by Product

Segment-wise performance

Monthly sales trend

Slicers

Year

Country

Segment

DAX measures were used to calculate key business metrics and enable dynamic analysis.

📌 Key Insights

Certain products generate higher profit margins despite lower sales volume

High discount levels have a negative impact on profitability

Sales performance varies significantly across regions and seasons

Specific segments consistently outperform others in profit contribution
